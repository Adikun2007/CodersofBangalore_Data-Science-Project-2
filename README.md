# Coders of Bangalore 🚀

### A data science project focused on transforming chaotic, unstructured social media data into clean, structured, and insight-driven information.

## 📌 Overview

#### Real-world data is rarely clean. This project takes raw text-based user data and converts it into a structured JSON format, making it both human-readable and analysis-ready. The goal is not just cleaning data, but extracting meaningful signals from noise.

## ⚙️ Approach
- Parsed unstructured text into logical user chunks
- Extracted key attributes (username, posts, followers, following, category, bio)
- Handled missing and inconsistent data robustly
- Converted processed data into structured JSON

## 📊 Analysis & Insights
- Identified users with maximum posts
- Found users with highest followers
- Analyzed users following the most accounts
- Categorized profiles (Digital Creator, Non-Profit, etc.)
- Generated concise insights from raw data

## 🧠 Key Highlights
- Strong focus on data preprocessing and cleaning
- Built for clarity, scalability, and real-world messy datasets
- Bridges the gap between raw data and actionable insights
